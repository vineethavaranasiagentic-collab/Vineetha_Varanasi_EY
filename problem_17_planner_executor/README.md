# Problem 17 — Planner and Executor

This folder contains the planner-executor workflow for Problem 16 semantic ticket search.

## Run

From this folder:

```powershell
Set-Location "c:\Users\user\Documents\AgenticAITraining\Vineetha_Varanasi_EY\problem_17_planner_executor"

c:\Users\user\Documents\AgenticAITraining\Vineetha_Varanasi_EY\.venv\Scripts\python.exe planner_executor.py
```

The script imports the semantic-search implementation from Problem 16. Keep both folders in their existing locations.

The workflow creates and prints a plan containing validation, model loading, ticket indexing, semantic search, and result reporting steps. Type `exit` to quit.
